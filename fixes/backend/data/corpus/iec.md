# Importer-Exporter Code (IEC)

_Starter summary written from general knowledge, not quoted from the source. Verify against the official source before relying on it._

A business that imports or exports goods commercially in India generally needs an Importer-Exporter Code issued by DGFT. It is tied to the entity's PAN and is needed for customs clearance. Obtain it early in the roadmap, because it is a prerequisite for many later steps. Some goods are restricted or need extra licences, which the DGFT policy lists by HS code.
