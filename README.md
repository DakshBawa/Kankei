# Kankei (関係)

**An AI-assisted India market-entry copilot for Japanese SMEs.**

Kankei walks a Japanese SME through the full journey of entering the Indian market in one connected flow: **Research → Match → Comply → Launch**, with a **Culture & Communication layer** available at every step.

> **Data notice:** All partner companies, trust signals and news snippets are **synthetic and fictional**. Compliance timelines, costs and duty rates are **indicative placeholders** and must be verified against official sources (CBIC, BIS, etc.) before any real use. Kankei is AI-assisted preparation; final sign-off belongs to a licensed professional.

---

## Features

### 1. Market Research Engine
- Ranks 10 to 12 Indian states with a transparent weighted opportunity score (demand, auto-cluster density, Japanese presence, logistics, incentives, land cost, talent).
- Interactive India choropleth map with a ranked side panel.
- Weight sliders that re-rank states live.
- "Why this state" cards showing the top contributing factors and their sources.
- One-click bilingual (JA/EN) market brief, 資料-style, generated with retrieval over a small document corpus and cited sources.

### 2. Partner Matchmaking and Verification
- **Fit Score**: product fit, geographic coverage, Japan-client experience, language capability and capacity, with competing-brand conflict detection.
- **Trust Score (0 to 100)**: corporate standing, GST regularity, litigation and insolvency, adverse media, Japanese-peer references and financial health proxy.
- Red flags are generated by code as facts (for example `director_linked_to_struck_off`). The LLM only phrases them in plain language, so there is no hallucination risk in the facts themselves.
- Entity resolution on duplicate records (name fuzzy matching plus GSTIN/CIN).
- Partner pipeline board: Discovered → Shortlisted → Verified → Meeting → Agreement, with an audit log.

### 3. Regulatory and Compliance Navigator
- **Rules engine first, AI second.** Rules live in `rules.yaml` as data.
- A questionnaire filters applicable rules, topologically sorts them by dependency and computes the critical path and total timeline range.
- Each step shows its authority, source link and last-verified date.
- Landed-cost calculator: CIF → basic customs duty → social welfare surcharge → IGST → logistics, with all rates configurable.
- Regulation-change monitor: paste a notification and get a summary plus a suggested rule update, queued for human review and never auto-applied.

### 4. GTM Execution Toolkit
- Pricing waterfall simulator from ex-factory price (¥) to final local price, with a competitor price band overlay.
- GTM model recommender comparing distributor-led, direct, e-commerce, OEM supply and JV on cash-flow need, time to revenue and risk.

### 5. Culture and Communication Layer
- **Message coach**: split-pane view that flags risky phrases (for example 前向きに検討します), explains how an Indian counterpart is likely to read them, and suggests a rewrite.
- Bilingual partner-introduction email drafts.
- Negotiation briefing cards (ringi/nemawashi vs. founder-led decisions, punctuality, follow-up cadence).

---

## Data Storage

Kankei intentionally does **not** use PostgreSQL, pgvector or any other database. All data is read from CSV and JSON files in `backend/data/` and loaded into memory when the backend starts. Anything the app needs to persist (partner pipeline stages, audit log, session state, cached LLM responses) is written to JSON files as well. This keeps setup to a single command and makes the app easy to run anywhere.

## Getting Started

### Prerequisites
- Python 3.10+
- Node.js 18+
- An API key for your chosen LLM provider

### 1. Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# configure your LLM provider
cp .env.example .env             # then add your API key

uvicorn app.main:app --reload
```

The API runs at `http://localhost:8000`, with interactive Swagger docs at `http://localhost:8000/docs`.

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000`.

### 3. Use the app

Open the app, fill in your company profile on the onboarding page, and follow the journey from Research through to Launch.

## User Flow

1. **Onboard**: enter your product category, buyer type (B2B/B2C), budget and priority weights.
2. **Research**: view the state ranking map, move the sliders to re-rank, and generate the Japanese brief.
3. **Match**: review ranked partners, their Fit and Trust scores, and red-flag explanations.
4. **Comply**: answer the questionnaire (for example import vs. local manufacturing) to get your roadmap, then run the landed-cost calculator.
5. **Launch (GTM)**: simulate the pricing waterfall and compare go-to-market models.
6. **Culture**: paste a message into the coach and see flagged phrases and rewrites.

## Design Principles

- **Facts from code, wording from the LLM.** Scores, red flags and compliance steps come from deterministic logic and data. The LLM explains and phrases; it does not invent facts.
- **Transparent scoring.** Every score shows its breakdown and the top contributing factors.
- **Sources everywhere.** Data points and rules carry a source and `last_verified` date.
- **Human in the loop.** Regulation updates are suggested, never auto-applied. A persistent banner reminds users that a licensed professional gives final sign-off.
- **Swappable LLM.** All model calls go through `llm.py`.

---

## Data and Legal Notes

- Partner names and records are fictional. No real company is labeled as risky.
- State-level figures are compiled from public sources (state industrial policies, Invest India, JETRO-style reports, RBI and Census data) and normalized to a 0 to 1 scale.
- Duty rates, timelines and costs are indicative and marked "verify" in the UI.
